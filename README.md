# Letbe - AI Football Prediction Platform

Letbe is a premium, AI-powered football prediction web application. It uses machine learning models (XGBoost) and Large Language Models (Gemini Pro) to provide high-accuracy insights and natural language match analysis.

## 🚀 Key Features
- **AI Predictions**: 1X2, BTTS, and Over/Under predictions powered by XGBoost.
- **Natural Language Analysis**: Detailed match commentary generated by Google Gemini.
- **Premium Dashboard**: Glassmorphism UI built with Next.js and Tailwind CSS.
- **Live Data**: Real-time fixture synchronization via API-Football.
- **Historical Analysis**: Deep learning from 10+ years of football statistics.

## 🛠 Tech Stack
- **Frontend**: Next.js 16, TypeScript, Tailwind CSS
- **Backend**: FastAPI (Python), XGBoost, Scikit-learn
- **Database**: Supabase (PostgreSQL)
- **AI**: Google Gemini Pro

## 📦 Project Structure
- `/frontend`: Next.js web application.
- `/backend`: FastAPI service and ML scripts.
- `/supabase`: SQL schema and database migrations.

## ⚙️ Setup Instructions

### Backend
1. Create a virtual environment: `python -m venv venv`
2. Install dependencies: `pip install -r backend/requirements.txt`
3. Configure `.env` with your Supabase, RapidAPI, and Gemini keys.
4. Run the API: `python backend/main.py`

### Frontend
1. Install dependencies: `npm install`
2. Configure `.env.local` with your Supabase public keys.
3. Run the dev server: `npm run dev`
